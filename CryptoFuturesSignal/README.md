# Crypto Futures Signal

Android app for indicator-based analysis of USDT perpetual futures markets.

Features:
- BTC, ETH, SOL, ADA, XRP futures dashboard
- Timeframes: 1m, 5m, 15m, 1h, 4h
- EMA 9/21, RSI 14, MACD, ATR, volume ratio, funding rate and open interest
- LONG / SHORT / WAIT rule-based scoring
- ATR-derived stop-loss and two reference targets
- Foreground monitoring service with signal-change notifications
- Binance Futures public data with Bybit Linear fallback
- No API keys and no trade execution

This is market-analysis software, not financial advice or a profit guarantee.
